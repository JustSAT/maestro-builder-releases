# Maestro Builder

A macOS app for manual QA engineers: write, edit and run [Maestro](https://maestro.dev) flows as a visual list of
steps, with the iOS simulator or Android emulator next to them.

This repository holds only the releases. Download the latest version from
[Releases](https://github.com/JustSAT/maestro-builder-releases/releases/latest).

## Install

You need a Mac with Apple Silicon (M1 or newer).

1. Download `Maestro Builder-<version>-arm64.dmg` from the latest release.
2. Open the `.dmg` and drag **Maestro Builder** into **Applications**.
3. Open Maestro Builder from Applications. The first time, macOS won't open it, because the app is not notarized
   by Apple yet. Close the message, then open **System Settings › Privacy & Security**, scroll down and click
   **Open Anyway**. After that the app opens normally.

## Update

In the app choose **Maestro Builder › Check for Updates…**. When a new version is out, it opens its download page:
download the new `.dmg` and drag the app into Applications again, replacing the old one. Your settings stay.

## Українською

Застосунок для macOS для мануальних QA-інженерів: створюйте, редагуйте й запускайте флоу
[Maestro](https://maestro.dev) як наочний список кроків, із симулятором iOS або емулятором Android поруч.

У цьому репозиторії лише релізи. Останню версію завантажуйте з
[Releases](https://github.com/JustSAT/maestro-builder-releases/releases/latest).

### Встановлення

Потрібен Mac з Apple Silicon (M1 або новіший).

1. Завантажте `Maestro Builder-<версія>-arm64.dmg` з останнього релізу.
2. Відкрийте `.dmg` і перетягніть **Maestro Builder** у **Програми**.
3. Відкрийте Maestro Builder з Програм. Першого разу macOS його не відкриє, бо застосунок ще не нотаризований
   Apple. Закрийте повідомлення, відкрийте **Системні параметри › Приватність і безпека**, прокрутіть униз і
   натисніть **Все одно відкрити**. Далі застосунок відкриватиметься як звичайно.

### Оновлення

У застосунку виберіть **Maestro Builder › Перевірити оновлення…**. Якщо вийшла нова версія, відкриється сторінка
завантаження: завантажте новий `.dmg` і знову перетягніть застосунок у Програми, замінивши старий. Налаштування
збережуться.
